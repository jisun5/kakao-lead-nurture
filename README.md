# kakao-lead-nurture

**한 줄:** 카톡 채널에 들어온 사람에게 보낼 메시지 세 통(웰컴·활용·다음 행동)을 카카오 규칙까지 맞춰 짜주는 스킬

## 어떤 스킬인가요
가두리망이 카카오톡 채널일 때 쓰는 스킬이에요. 채널 추가는 잘 들어오는데 그다음에 뭘 보내야 할지 막힐 때, 그리고 (광고) 표기·수신거부·야간 발송 같은 카카오 규칙이 헷갈릴 때요.

이메일 CRM이랑은 사정이 달라요. 폼이 없어서 웰컴 메시지가 곧 완료 화면이고, 기존 친구한테는 웰컴이 안 나가고, 밤에 추가한 사람은 다음 날 아침에야 메시지를 받아요. 이런 걸 모르고 문안만 쓰면 "안 왔다"는 채팅부터 받습니다.

## 뭘 해주나
다섯 개만 물어보고 `crm-messages.md` 한 장을 만들어줘요.

- 세 통의 역할표 — ①들어온 직후(자동) ②며칠 뒤 선물을 쓰게 만드는 메시지 ③다음 행동 요청
- 카톡 채널 형식 그대로의 문안 세 통 (제목·본문·버튼·수신거부)
- 발송 캘린더 + "친구 N명 × 통수" 비용 줄
- 관리자센터 세팅 체크리스트 (웰컴 등록 → 자동응답 키워드 → 야간 안내 문구 → 기존 친구용 전체 메시지 → 본인 폰 테스트)
- 요청하면 이메일·문자·DM·오픈채팅방 변형

②는 "열어보세요"라고 안 하고 선물 안의 문장 하나를 통째로 꺼내 보여주게 시켜요. 열어본 사람만 ③에 반응하더라고요.

## 더 하고 싶은 말
2회차·3회차 과제로 무료 PDF 나눔을 카톡 채널로 2주 돌리면서 실제로 나간 문안 세 통이 그대로 참고 자료에 들어 있어요. 6일간 31명이 들어오고 4명이 나갔는데(13%), 웰컴에서 판매 버튼을 두 번째에 작게 둔 게 이탈을 낮춘 것 같아요.

카톡 채널은 누가 들어왔는지 카카오가 쥐고 있어서 숫자만 보여요. 이름을 알고 싶으면 답장을 유도하는 수밖에 없어서, 팔 게 없을 때의 ③은 답장 유도형으로 넣어뒀어요.
