## 2. 문안 세 통

### ① 웰컴 메시지 — 들어온 직후 (자동)

```
채널: 카카오톡 채널 웰컴 메시지 (자동)
언제: 즉시 (야간 추가자는 익일 08:00 이후)
제목: (광고) 요가하는 하루
본문:
약속드린 아침 스트레칭 PDF, 바로 보내드릴게요 🎁
요가하는 하루입니다. 채널 추가 감사합니다.

📄 아침 10분 스트레칭 루틴 PDF(6p)
[[PDF 구성 한 줄 — 예: 침대에서 1분 → 목·어깨 3분 → 허리·골반 4분 → 마무리 호흡 2분]]

유튜브 구독자 1,000명 기념으로 9/20(일)까지만 무료로 드려요.

매일 혼자 하기 어렵다면, 4주 온라인 그룹 클래스(월 4회)도 열려 있어요.

[스트레칭PDF받기]  [그룹클래스보기]
수신거부: 홈 > 채널 차단
```

- 버튼1 링크: `[[PDF 링크]]` / 버튼2 링크: `[[클래스 신청 링크]]`
- 판매 버튼은 두 번째, 한 줄만. 첫 줄은 랜딩·유튜브에서 약속한 표현("아침 10분 스트레칭 루틴 PDF")을 그대로 되받는다.
- 이름 치환 없음. 발신명 뒤 이모지 없음.

### ② 활용 메시지 — D+5 · 9/15(화) 09:00

```
채널: 카카오톡 채널 전체 메시지
언제: 9/15(화) 09:00 (D+5)
제목: (광고) 요가하는 하루
본문:
스트레칭 PDF, 한 번은 펼쳐보셨나요? 📄
6페이지 중 [[N]]페이지 동작 하나만 꺼내 볼게요.
"[[PDF 안의 동작 이름 + 방법 한 문장 — PDF 원문 그대로]]"
이 동작 하나만 해도 아침에 몸이 절반은 풀립니다.

아직 안 열어보셨다면 👇
[PDF 다시 받기]

수신거부: 홈 > 채널 차단
```

- 셋째 줄은 반드시 **PDF에 실제로 있는 문장**으로 채운다(지어내지 않음). 없는 동작을 쓰면 열어본 사람이 바로 안다.
- 버튼 링크: `[[PDF 링크]]`

## 3. 발송 캘린더 + 비용 줄

| 일차 | 날짜 | 무엇 | 채널 | 비고 |
|---|---|---|---|---|
| D0~ | 9/10(목)~ 상시 | ① 웰컴 메시지 | 신규 추가자 자동 | 야간 추가자는 익일 08:00 · 기존 친구 0명이라 전체 메시지 D0 발송 없음 |
| D+5 | 9/15(화) 09:00 | ② 활용 메시지 | 전체 메시지 | 캠페인 중간 |
| 마감 D-2 | 9/18(금) 10:00 | ③ 다음 행동 | 전체 메시지 | 9/20(일) 마감 이틀 전 |
| 마감 | 9/20(일) | (발송 없음) | — | PDF 링크 유지 여부 결정 |

**비용 줄**: 전체 메시지 2통 × 발송 시점 친구 `[[M]]`명 = `[[2M]]`건 → 단가 `[[빈칸]]`원 (관리자센터 > 메시지 > 요금에서 확인). 웰컴 메시지는 무료(자동 발송).
지금 0명이므로 ② 발송 전날 친구 수를 확인해 M을 채운다.

## 4. 세팅 체크리스트 (카카오톡 채널 관리자센터 center-pf.kakao.com)

- [ ] 채팅 > **웰컴 메시지** 등록 — 이미지(선택) + ① 본문 + 버튼 2개(`스트레칭PDF받기`→PDF 링크, `그룹클래스보기`→클래스 링크)
- [ ] 채팅 > 자동응답 > **키워드 1개** 등록 (예: "스트레칭" → PDF 링크 재발송). 웰컴을 놓친 사람의 구제 경로
- [ ] **야간 안내 문구** 게시 — 채널 홈 소개 · 유튜브 영상 설명란/커뮤니티 탭 · 인스타 캡션에 "야간(20:55~익일 08:00) 추가 시 익일 오전 8시 이후 웰컴 메시지 발송" 한 줄
- [ ] ~~기존 친구용 전체 메시지 예약 (D0 08:00)~~ — 친구 0명이라 해당 없음
- [ ] ②(9/15 화 09:00) · ③(9/18 금 10:00) 전체 메시지 **예약 발송** 등록 — (광고) 표기·수신거부 줄 확인
- [ ] **내 폰으로 채널 추가해서 ① 수신 테스트** — 두 버튼 링크가 실제로 열리는지
- [ ] 마케팅 수신동의 근거 정리 — "채널 추가 = 채널 메시지 수신 동의(카카오 채널 약관)" 입장, 철회 수단은 채널 차단. 클래스 신청 페이지에서 이름·연락처를 받는다면 그 폼은 `privacy-check`로 점검
- [ ] 2년마다 수신동의 재확인 고지 의무 — 카톡 채널은 개인별 동의 날짜가 없으므로 이 의무를 어떻게 볼지 **사용자가 별도 확인**
- [ ] 통계 > 상세 통계에서 **일자별 친구 추가 / 차단 수** 기록 시작 (개인 식별 불가, 숫자로만)

**카카오 채널에서 안 되는 것**: 개인별 발송 시각 · 개인별 열람 여부 · 친구 명단 다운로드 · 이름 치환. 리드를 식별하고 싶으면 답장 유도로 간다(채팅 건 사람만 이름이 보임).
