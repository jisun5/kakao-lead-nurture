# 메시지 플레이북 — 실제 나간 문안과 변형 패턴

아래 ①②③은 2026년 9월 실제 캠페인(무료 PDF 나눔 2주, 카카오톡 채널 가두리망, 기존 친구 167명)에서 쓰인 문안이다. **구조를 베끼고 내용은 사용자의 것으로 바꾼다.** 문장을 그대로 옮기지 않는다.

## ① 웰컴 메시지 — 들어온 직후 (자동)

```
채널: 카카오톡 채널 웰컴 메시지 (자동) — 기존 친구에게는 런칭일 08:00 전체 메시지로 동일 문안
제목: (광고) 에듀파이교육센터
본문:
반갑습니다!
에듀파이교육센터(EduFi)입니다 🙌
채널을 추가해주셔서 감사합니다.

약속드린 선물, 바로 보내드릴게요 🎁

📕 무료 PDF 자료 구성(18p)

10년차 강사의 워크숍 준비법 + 사전 체크리스트 + AI 활용 워크숍 준비 노하우 + 교육담당자·강사들이 자주 묻는 질문 15가지 답변까지!

📖 이 노하우의 실전 전체 버전이 궁금하다면 → 조직 소통 워크숍 사례집 [패키지 4종] 확인 클릭!
(전자책 85p + 워크시트 6종 + PPT 강의안 원본 + 활용영상)

[PDF 자료다운]  [패키지4종확인]
수신거부: 홈 > 채널 차단
```

**구조 해부**
| 줄 | 역할 | 바꿀 때 |
|---|---|---|
| 반갑습니다 / 발신명 / 감사 | 누가 보냈는지 3초 안에 | 발신명은 채널명과 똑같이 |
| "약속드린 선물, 바로 보내드릴게요" | 이 통의 용건. 미리보기에 걸리는 문장 | 랜딩에서 약속한 표현을 그대로 되받는다 |
| 📕 구성 한 줄 나열 | 열어볼 이유. 목차를 미리 보여준다 | 항목 3~4개, 한 줄에 |
| 📖 다음 단계 한 줄 + 괄호 구성 | 2차 전환 씨앗. **작게, 두 번째로** | 팔 게 없으면 통째로 삭제 |
| 버튼 2개 | 선물이 먼저 | 버튼 이름 4~8자 |
| 수신거부 | 광고성이므로 필수 | 판매 언급을 지우면 (광고)·수신거부도 뺄 수 있다 |

**같이 게시한 안내 문구** (채널 홈·랜딩·릴스 캡션):
> 야간(오후 8시 55분 ~ 익일 오전 8시)에 채널을 추가한 경우, 카카오 정책에 따라 익일 오전 8시 이후 자료 링크가 담긴 웰컴 메시지를 받으실 수 있습니다 😊

**결과**: 6일간 친구 추가 31명 중 차단 4명(13%). 판매 버튼을 두 번째에 작게 둔 것이 이탈을 낮췄다고 판단.

## ② 활용 메시지 — D+7, 캠페인 중간

```
채널: 카카오톡 채널 전체 메시지
언제: 9/8(월) 오전 9시 (D+7)
제목: (광고) 에듀파이교육센터
본문:
PDF 받아보셨나요? 📕
PART 1 "교육담당자에게 먼저 묻는 질문" 중
하나만 뽑아드릴게요.
"이번 워크숍이 끝나고, 참가자가 딱 한 가지를 가져간다면 무엇이면 좋겠어요?"
이 질문 하나로 워크숍 방향이 절반은 정해집니다.

아직 안 열어보셨다면 👇
[PDF 다시 받기]

수신거부: 홈 > 채널 차단
```

**핵심은 넷째 줄이다.** 선물 안에 있는 문장 하나를 통째로 꺼내 보여준다. "열어보세요"라고 부탁하지 않고, 열어보면 이런 게 있다는 걸 증명한다.

**변형 패턴 (선물 종류별)**
| 선물 | ②에서 꺼내 보여줄 한 조각 |
|---|---|
| PDF 가이드·체크리스트 | 질문 하나 / 체크 항목 하나 + "이거 하나로 ○○가 절반" |
| 노션 템플릿 | 템플릿의 칸 하나를 채운 예시 스크린샷 + "이 칸부터 채워보세요" |
| 영상 강의 | 타임코드 하나 "07:20부터 3분만 보세요" |
| 할인 쿠폰·체험권 | 쿠폰으로 살 수 있는 것 중 가장 싼 것 하나 + 남은 기간 |
| 커뮤니티 입장 | 방에서 오늘 나온 질문 하나 + "답은 방에" |

## ③ 다음 행동 요청 — 마감 D-2

```
채널: 카카오톡 채널 전체 메시지
언제: 9/12(금) 오전 10시 (무료 나눔 마감 이틀 전)
제목: (광고) 에듀파이교육센터
본문:
무료 PDF 나눔이 9/14(일)에 끝납니다.

PDF의 "실전 전체 버전"이 궁금하셨다면,
조직 소통 워크숍 사례집 패키지 4종을 열어보세요.
전자책 85p · 워크시트 6종 · PPT 강의안 원본 · 활용영상

[사례집 패키지 보기]

수신거부: 홈 > 채널 차단
```

**순서**: 마감 사실 → "궁금하셨다면" 조건절 → 구성 한 줄 → 버튼 하나. 가격은 본문에 넣지 않고 판매 페이지에 맡긴다(SNS 게시 제한·메시지 길이 모두 유리).

**팔 것이 없을 때의 ③ (답장 유도형)**
```
(광고) 표기 불필요 — 판매 언급 없음
본문:
PDF 나눔이 O일에 끝납니다.
받아보신 분들께 하나만 여쭐게요.
지금 준비 중인 워크숍(또는 ○○)이 있으세요?
한 줄만 답장 주시면, 맞는 자료를 골라 보내드릴게요.
```
→ 채팅을 걸어온 사람만 이름이 보이는 카톡 채널 특성상, **답장 유도가 곧 리드 식별**이 된다.

## 흔한 실수 — 문안을 내기 전에 걸러낸다

- [ ] ①에 판매 버튼이 첫 번째로, 크게 들어가 있다 → 두 번째로 내리거나 ③으로
- [ ] ②가 "열어보셨나요? 꼭 보세요"로 끝난다 → 내용 한 조각을 꺼내라
- [ ] ③에 마감·구성·가격·후기·FAQ가 다 들어 있다 → 마감 + 구성 + 버튼만
- [ ] 판매 언급이 있는데 (광고)·수신거부가 없다
- [ ] 전체 메시지 예약이 20:00 이후 또는 08:00 이전이다
- [ ] 기존 친구가 있는데 전체 메시지 계획이 없다
- [ ] `{이름}님`처럼 카톡 채널에서 안 되는 치환을 썼다
- [ ] 없는 숫자(다운로드 수·후기)를 썼다
