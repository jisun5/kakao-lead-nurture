# 카카오톡 채널 규칙 — 문안과 세팅에 걸리는 것만

법률 자문이 아니다. 아래는 2026년 9월 실운영에서 확인한 내용과 공개된 법 조항을 요약한 것이며, 카카오 채널 운영정책은 바뀐다. 발송 전 관리자센터 공지를 다시 본다.

---

## 1. 광고성 메시지 표기 (정보통신망법 §50)

| 항목 | 규칙 | 문안에서는 |
|---|---|---|
| (광고) 표기 | 영리 목적 광고성 정보는 제목 첫머리에 `(광고)` | `제목: (광고) 발신명` |
| 발신자 표시 | 보내는 사람의 명칭 | 발신명 = 채널명과 동일하게 |
| 수신거부 방법 | 쉽게 거부할 수 있는 방법 명시 | 말미 `수신거부: 홈 > 채널 차단` |
| 야간 전송 제한 | 21:00~08:00 광고성 전송은 별도 야간 수신동의 필요 | 전체 메시지 예약은 08:00~20:00 안에서 |

**무엇이 광고성인가**: 판매·할인·이벤트·유료 상품 소개가 한 줄이라도 있으면 광고성으로 본다. 순수 안내(주문 확인, 약속한 무료 자료 링크만)는 아닐 수 있으나, **애매하면 광고성으로 처리**한다. (광고)를 붙여서 손해 보는 일은 없다.

---

## 2. 웰컴 메시지 (관리자센터 > 채팅 > 웰컴 메시지)

- 채널 추가 즉시 자동 발송. 이미지 + 본문 + **버튼 최대 2개**(링크).
- **야간 추가자**: 실운영 기준 20:55~익일 08:00 사이 추가한 사람에게는 **익일 08:00 이후** 발송된다. 즉시 받을 거라 기대한 사람이 "안 왔다"고 채팅을 걸어온다 → 랜딩·SNS 캡션·채널 홈에 안내 문구를 미리 적는다.
- **기존 친구에게는 다시 나가지 않는다.** 이미 친구인 사람은 웰컴을 못 받으므로 런칭일 08:00 전체 메시지로 같은 문안을 보낸다.
- 웰컴을 못 받은 사람의 구제: **자동응답 키워드**(예: "가이드" 입력 → 링크 재발송)를 하나 등록해 둔다.

---

## 3. 전체 메시지

- 친구 전원에게 한 번에 발송. **건당 과금**(단가는 관리자센터 > 메시지 요금에서 확인).
- 예약 발송 가능 → ②③은 캘린더대로 예약해 둔다.
- 개인별 치환(`{이름}`), 개인별 발송 시각, 개인별 열람 여부 **불가**. 문안은 전원에게 같은 말로 쓴다.
- 통계는 발송 수·클릭 수 수준. 개인 추적은 안 된다.

---

## 4. 누가 들어왔는지 — 카카오가 쥐고 있다

| 알 수 있는 것 | 알 수 없는 것 |
|---|---|
| 일자별 친구 추가 수 · 차단 수 · 채팅 요청 수 (상세 통계, 엑셀 다운로드) | 개인별 연락처 · 이메일 · 실명 |
| 채팅을 걸어온 사람의 카톡 프로필명과 대화 내용 | 개인별 추가 시각 · 유입 경로 |
| 친구 목록의 닉네임·프로필 사진 | 친구 명단 다운로드 (정책상 불가) |

**함의**
- 폼·DB·RLS·어드민이 통째로 사라져 세팅이 가볍다. 대신 "숫자만" 본다.
- 리드를 식별하고 싶으면 **답장을 유도**한다(③의 답장 유도형). 채팅을 건 사람만 이름이 보인다.
- 나중에 이메일·문자로 옮겨 가려면 별도 폼이 필요하고, 그때는 `lead-form` + `privacy-build`로 간다.

## 5. 마케팅 수신동의 — 채널 추가로 갈음할 때

- 입장: 카카오톡 채널 추가 = 채널 메시지 수신에 동의(카카오 채널 이용약관 기준). 철회 = 채널 차단.
- 이 입장을 택하면 **별도 동의 폼을 만들지 않는다**. 랜딩에 수집 항목이 없으므로 처리방침도 새로 쓸 필요가 없고, 운영 주체의 기존 처리방침(홈페이지)을 적용한다.
- 단, 랜딩이나 다른 경로로 이름·연락처를 **한 칸이라도 받으면** 이 입장은 무너진다. 그 순간 `privacy-check`로 점검한다.
- 2년마다 수신동의 재확인 고지 의무는 "동의한 날짜" 기록이 있어야 이행할 수 있다. 카톡 채널은 개인별 날짜가 없으므로, 이 의무를 어떻게 볼지는 **사용자가 별도 확인**해야 한다고 산출물에 남긴다.

---

## 6. 세팅 동선 (관리자센터 center-pf.kakao.com)

1. 채팅 > 웰컴 메시지 > 등록 (이미지·본문·버튼 2개)
2. 채팅 > 자동응답 > 키워드 1개 (선물 링크 재발송)
3. 메시지 > 전체 메시지 > 새 메시지 > **예약 발송** (D0 08:00 / D+7 / 마감 D-2)
4. 채널 홈 > 소개 문구에 야간 안내 한 줄
5. 통계 > 상세 통계 > 일자별 친구 추가·차단 (엑셀) — 캠페인 대장에 매일 옮긴다
6. 본인 폰으로 채널 추가 → ① 수신 → 버튼 링크 열림 확인 → 그다음 끝
